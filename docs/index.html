Know what happens to your files

Review first. Remove with care.

Deletion behavior depends on the tool. Read the confirmation and keep backups of files you need.

Some removals use Trash

User-level app uninstalling, orphan removal, and exact-duplicate removal move selected files to Trash. Recovery is possible until you empty it.

Some cleanup is permanent

Dashboard and category cleanup, scheduled auto-clean, Trash emptying, Docker and simulator cleanup, administrator-authorized removal, local snapshot deletion, and CLI cleanup can permanently delete data.

Local scans. No telemetry.

Scan results and file paths stay on your Mac. PureMac does not collect analytics or crash reports. GitHub release checks and Homebrew updates use the network.

You control the scope

Review manual selections and excluded paths. Scheduled auto-clean runs unattended once enabled. Full Disk Access lets scans reach protected locations.

A few things to know.

Is PureMac completely free?

Yes. The app and CLI are open source under the MIT license, with no trial, subscription, or paid feature tier. Browse the source on GitHub.

Can I undo a cleanup?

Only files moved to Trash can be restored from it, and only before it is emptied. Several cleanup tools permanently delete data. Review the removal behavior and the app’s confirmation before continuing.

Why does it ask for Full Disk Access?

macOS protects locations such as Mail downloads and app containers. Full Disk Access lets PureMac scan those locations. Without it, some results will be incomplete. You can manage access in System Settings.

Does PureMac work offline?

Local scanning and cleanup work offline. Checking GitHub for a PureMac release and checking or installing Homebrew app updates require a network connection. PureMac does not upload your scanned paths or file contents.

Will it free all purgeable space?

No. macOS manages purgeable storage. PureMac shows it separately rather than counting it as junk that it can reliably remove.

Where can I get help or report a problem?

Read the troubleshooting guide or open an issue. Review logs and screenshots for personal file paths before posting them publicly.
