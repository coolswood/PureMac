Privacy policy

Updated 24 October 2026

PureMac is a free, open-source utility for local Mac cleanup, app management, storage exploration, and system checks.

Data collection

PureMac does not collect telemetry, usage analytics, or crash reports. It has no accounts or advertising. The app does not upload your scanned file paths, scan results, or file contents to the developer.

What stays on your Mac

Scans and cleanup run locally. Preferences, exclusions, ignored items, and local app state remain on your Mac. Full Disk Access allows PureMac to read protected locations such as Mail downloads and app containers; without it, some scans may be incomplete.

Network access

Local scanning and cleanup work offline. When you request a PureMac update check in Settings, the app contacts GitHub for release information. Opening release links or downloading an update also contacts GitHub.

Checking or installing updates for Homebrew-managed apps invokes Homebrew and its package sources. PureMac runs these Homebrew operations with Homebrew analytics disabled. Those services receive the network information needed to handle requests, such as your IP address. Their own privacy policies apply.

File removal

Not all removal is recoverable. Read the relevant confirmation before proceeding and keep backups of important files.

  • User-level app uninstalling, orphan removal, and exact-duplicate removal move selected files to Trash. They can be recovered from Trash until it is emptied.
  • Dashboard and category cleanup, scheduled auto-clean, Trash emptying, Docker and Xcode runtime cleanup, administrator-authorized removal, local snapshot deletion, and CLI cleanup can permanently delete data.
  • Manual removal requires confirmation. Scheduled auto-clean operates unattended once enabled. Exclusions apply to cleanup and scheduled runs.
  • Similar Photos is a review tool and does not delete photos. Protection reviews system configuration; it is not an antivirus scanner.

This website

This site is hosted on GitHub Pages. The refreshed pages do not embed analytics, advertising, or third-party fonts. GitHub may process request information to operate its hosting service. See the GitHub privacy statement.

Support and source

Open a GitHub issue for questions. Issues are public, so remove personal file paths or other sensitive information before attaching logs or screenshots. You can inspect the implementation in the source repository.
